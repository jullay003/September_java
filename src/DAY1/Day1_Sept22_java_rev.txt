2. Primitive vs Reference Type:
 prim : copy of the value. == : values are compared
 refer: both holds a reference to the same object. == : Objects references are compared.

if a.equals(b) == true
then
a.hashCode() == b.hashCode()

pass by value: Java passes the value into method. The method changes its own copy.
The reference itself is a passed by value, but the copied reference points to the same object
So both can modify that same object.
java is always pass by value. For objects, the value being passed is a copy of the reference.

Primitive:
== → compares values

Reference:
== → compares references
      (same object or different object)

hashCode():
→ completely separate mechanism
